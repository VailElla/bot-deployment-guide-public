# 模型方案：聊天、记忆、识别与语音

本页记录该部署在 2026 年 10 月 31 日核对的模型路由和此前的语音部署回执，供复现类似方案时参考。这是一个有日期的配置快照，不是上游默认配置；模型可用性、名称、订阅资格、插件及硬件要求都可能变化。定制桥接、语音适配和训练器不在本仓库发布，不能只填写名称就获得完整功能。

| 用途 | 模型或方案 | 使用方式与边界 |
| --- | --- | --- |
| 日常文本、群聊及图片理解 | `gpt-6.1-terra`，推理强度 `low` | 通过本机 Codex CLI 和定制 AstrBot 桥接调用；图片理解需桥接和模型输入都支持图片 |
| 长期记忆整理 | 同为 `gpt-6.1-terra`，推理强度 `medium` | 独立模型提供商配置供记忆总结使用；与日常聊天的 `low` 配置分开，后台调度与额度仍受限制 |
| 长期记忆向量检索及话题辅助分段 | `BAAI/bge-small-zh-v1.5`，512 维 | 本地 CPU 嵌入，通过定制适配接入；向量模型负责相似度表示，不代替聊天模型或判断访问权限 |
| QQ 输入语音 | QQ 原生转写优先，随后可选已配置 STT，本地回退 `Qwen3-ASR-0.6B` 的 `Q4_K_M` GGUF | 本地输入使用自动语种；不同转写层分别有预算，失败不猜测内容 |
| 视频音轨与生成语音复核 | 同一 `Qwen3-ASR-0.6B Q4_K_M` 本地模型 | 视频音轨用自动语种，输出复核用中文；与输入回退共用跨进程锁，避免同时占用模型 |
| 语音回复 | GPT-SoVITS V5 Dev 定制链路：520 条训练的 GPT 第 40 轮 + CFM 全参数第 12 轮 | 中文、无参考、整段合成；权重、定制代码与录音未公开，需使用有权使用的自有素材 |

表中的 QQ 原生转写没有可核实的公开模型名称，因此不把本地 Qwen 称为 QQ 原生模型。视频画面走抽帧和聊天模型的图片输入；音轨走本地转写，不代表系统具备连续视频理解。具体的转写、并发和排队流程见 [ASR 与消息调度方案](asr-message-scheduling.md)。

## 语音合成示例参数

以下为部署回执中的一组参数，适用于对应的定制 V5 Dev 推理实现；字段的含义与支持情况须以实际版本为准。

| 参数 | 示例值 |
| --- | --- |
| GPT 语义模型 / CFM 声学模型 | 第 40 轮 / 全参数第 12 轮 |
| temperature / top-k / top-p | 0.8 / 15 / 1.0 |
| 重复惩罚 / CFG / 声学步数 | 1.45 / 1.35 / 32 |
| 输入与长度保护 | 中文整段；示例上限 100 个中文字符及数字、640 语义 token |
| 资源管理 | 按需加载，空闲约 600 秒后卸载；活动请求与租约阻止卸载 |

这一组训练记录为 520 条训练、无独立验证集；第 40 轮由部署者指定，不能称作依据独立验证集选出的最优检查点。参数是复现对照的起点，不保证音色、发音或稳定性；更换模型或数据后应重新听验。训练过程、检查点选择及独立评估的设计见 [V5 Dev 训练方案](v5-dev-training.md)，推理、质量门与发送链路见 [语音系统指南](voice-system.md)。

语音服务采用按需加载。健康接口中的已配置 profile 与模型实际驻留是不同状态：空闲卸载后可以看到服务存在但 worker 未加载；下一次受支持请求才按策略加载。历史配置回执或健康接口都不能证明当前每条语音合成、QQ 发送和接收端播放均成功。

## 迁移时如何选型

1. 分开验证聊天、记忆总结、嵌入、ASR 和 TTS，不将其中一种模型当作另一种的替代。先打通文本，再接入语音和多模态。
2. 核对真实可用的模型名称、接口、推理强度及限额；目标账号没有对应模型时选择兼容替代，并重新测工具、图片及上下文行为。
3. 嵌入模型改变时重建或迁移对应索引，检查维度和版本，不能混用不同模型的向量。用户、群和私聊的访问隔离应由应用层验证。
4. ASR 在目标语言、噪声、长录音和重叠语音上分别测试；更大的模型或更高精度应先做相同数据对照，不能仅凭参数量宣称效果更好。
5. 语音权重与源码、前端和推理模式必须匹配；记录授权、版本与哈希，先在隔离环境测试，再按授权验证接收端实际播放。不要把私有权重、训练材料、凭据或聊天音频放入公开仓库。
