# 消息频率、冷却与投递预算

以下是本项目维护源码的示例策略，并非 QQ 或 AstrBot 的官方默认值。可用代码和安装方法见 [消息频率限制组件](../components/message_limits/README.md)。该插件独立运行；不要与原本机 Codex 桥接的同类钩子或旧私聊限频插件叠加启用。下面的计数与结果按当前整理的实现说明，不表示真实平台已经验收。

## 策略和实现位置

| 范围 | 策略 | 代码与边界 |
| --- | --- | --- |
| 个人模型请求 | 同平台实例、Bot 账号、发送者跨群和私聊共享滚动 60 秒最多 5 轮；同一个入站事件的工具续轮不重复计数。 | `personal_limit.py` 与 `on_llm_request` 钩子；只在模型请求阶段扣额，普通不触发模型的入站消息不计。 |
| 群模型请求 | 同平台实例、Bot 账号和群共享滚动 60 秒最多 5 轮；群额已满时不扣个人额度。 | `personal_limit.py`；个人与群额度在同一 SQLite 事务中判断；超限停止本轮，不延长窗口。 |
| 防重复与循环 | 相同发送者、群和内容的请求 300 秒内重复静默；忽略引用信封 ID，规范化文本的空格与大小写。自己发出的群消息不触发。 | `loop_guard.py`；附件等非文本组件参与签名。仅适用于可见的事件，并非内容审核或平台消息 ID 去重。 |
| 成功后的单次续聊 | 明确唤醒并成功交付模型回复后，同平台、群、发送者 60 秒内可免再次唤醒接话一次；在接纳时消耗，失败也不恢复。 | `group_followup.py`；要求新的文字消息；指向他人、全体或命令等不会消耗正常接话。普通随机插话和续聊不会开启新窗口。 |
| 随机插话 | 群级 300 秒冷却；选中前再次检查，在入队前占位，成功发送后再计时。直接 @ Bot 时重置该群冷却；明确请求不等待此冷却。 | `group_followup.py`、`proactive_guard.py`；还受 `loop_guard.py` 的 120 秒安静期及模型请求阶段的群／个人额度约束。`disable_random_groups` 可按群关闭。概率由 AstrBot 的随机回复设置决定，本插件不设概率。 |
| 入群欢迎 | 同平台、Bot、群 120 秒最多接纳一次入群事件；失败也占用窗口，重复处理同一个内存事件不延长。 | `join_welcome.py`；SQLite 持久化，插件只放行或阻止事件，不提供欢迎文本或生成逻辑。 |
| 群回复发送 | 同群按票据顺序交付；本地不再施加发送次数等待，也不设 8 张待交付票据上限。 | `group_delivery.py`；明确 QQ 群限额拒绝后停止该事件的后续发送，不自动重发。平台仍可能按自己的策略拒发。 |
| 文本分段节奏 | 平台实例 ID 为 `snowluma` 的模型纯文本首段不延时，后续段之间随机 0.4–0.8 秒；其他场景沿用框架。 | `reply_pacing.py`；这是间隔策略，不是平台配额。可用 `reply_pacing=false` 关闭。 |
| 故障通知 | 同类别 600 秒冷却，跨类别至少相隔 30 秒；冷却期内聚合。容量不足静默，但正文或语音拒发应识别为交付失败。 | `incident_aggregation.py`；本仓库提供聚合类和测试，默认**未接线**至日志或 QQ，需另行集成。失败后的重试等待 30 秒，必须确认回执。 |
| 表情包节奏 | 原设计参考每三次完整回复搭配一次，实际取决于语境与用户要求，明确要求配图可例外。 | 模型偏好，不是硬限额；需要单独的表情插件和合法素材，此组件不包含。 |

## 顺序与边界

1. OneBot 事件进入时检查欢迎和重复事件；群事件经过唤醒及续聊判断。仅即将调用模型时才检查个人和群共享额度；普通闲聊与不调用模型的命令不扣额度。
2. 随机请求需要先通过群冷却及原生随机判断，再在异步返回后复查并预留，避免多个候选同时占用。@ 其他成员、@ 全体或只有昵称文字不重置 300 秒群冷却。
3. 生成后，平台实例 ID 为 `snowluma` 的普通非流式群聊按票据顺序投递；相邻轮次的模型生成与之前的交付可重叠。此机制不覆盖所有后台插件、其他平台或真正流式路径。
4. 本地不为输出追加发送限速；QQ 自身仍可能拒绝或限流。发送失败和状态不明确时不应自动重放。取消、失败、重载和停止需要排空或释放对应票据。

模型请求额度和欢迎冷却使用 SQLite 事务；群去重、续聊和随机状态在单个运行实例内同步预留并保存到文件，**不构成完整的多进程分布式限流**。状态虽使用哈希，低熵标识仍可能被推测，应限制本机访问。升级时使用新的 `personal_attempts.sqlite3`，不自动导入旧私聊和群额度计数；历史文件按本地保留策略处理。

## 验收

用虚构账号测试个人跨群／私聊及同群第 5/6 次模型请求、60 秒边界、群拒绝不扣个人额度、同事件并发重入；再测试重复内容、续聊、随机冷却、入群欢迎、同群顺序、超过 8 张交付票据、明确 299 不重发、取消与重载。检查群正文拒发仍能进入实际告警接线。最后用授权测试账号和接收端核对真实行为。
