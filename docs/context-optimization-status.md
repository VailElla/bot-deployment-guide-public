# 上下文优化：公开组件与边界

下表帮助读者区分已经提供的代码、需要额外接线的参考实现，以及当前尚未完整发布的功能。它是复现指南，不是目标机器的实时运行状态；安装前请核对固定上游版本和各组件说明。

| 能力 | 本仓库提供 | 使用边界 |
| --- | --- | --- |
| 群消息归属与引用 | [群聊上下文组件](../components/group_context/README.md)按平台、机器人及群隔离短期背景，保留发送者和真实引用链；触发后的消息不进入该轮。 | 背景有数量、时间和字符预算，不是完整群历史；规则筛选不能保证模型理解正确。 |
| 追问机器人已发文字 | 同一组件可从有限的 SnowLuma 群历史中回取经账号、群和时间核验的机器人文字。 | 需要平台支持只读历史接口；无法取得或无法核验时不补取，不读取私聊。 |
| 个人与群长期记忆 | [LivingMemory 补丁](../components/livingmemory/README.md)提供固定版本适配、来源作用域、分批总结、有限重试及恢复；2.8.4 另提供称呼、风格、问候和近期候选处理。 | 用户层是否跨群、数据保留与删除须由部署者决定并测试；这些偏好不是任意指令，不能代替身份认证。 |
| 总结与存储可靠性 | 两个上游版本的补丁均处理写事务取消、单条总结失败和限定的 SQLite BUSY 插入重试。 | 未知提交结果不重放；独立测试不等于生产数据库已恢复或上游模型已可用。 |
| 图片上下文与容量 | 群组件提供未接线的历史图片参考；`image_archive_v2.py` 提供带引用保护的内容去重和容量淘汰参考。 | 须另行接线并确认授权、备份、迁移及淘汰策略；安装群组件本身不会启用图片持久化。 |
| 消息请求窗口 | [消息频率组件](../components/message_limits/README.md)支持个人 3/60 秒、20/600 秒和群 5/60 秒原子准入及同群有序交付。 | 配额不是平台默认值；旧版未保留的长窗口记录不会凭空恢复。 |
| 会话轮换、无正文唤醒、图像关联、工具和完整语音链路 | 分别有设计说明或部分参考代码。 | 完整桥接及配套接线仍未发布；不能仅通过安装上述组件宣称端到端复现。 |

各测试使用合成数据；真实 QQ 收发、手机端展示、模型理解、目标系统兼容及长期稳定性需要各自在授权环境验收。
